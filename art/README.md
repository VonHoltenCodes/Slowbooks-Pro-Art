# art/

Accepted pieces live here, by avenue. A folder is empty until something lands in it.

- `mascot/` — the turtle (and the Hare): poses, expressions, reference sheets
- `app-icons/` — icon sources and exports
- `social/` — finished posts, by date and platform
- `website/` — hero and feature illustrations
- `marketing/` — flyers, slides, stickers, badges
- `video/` — thumbnails, project files, and links to the videos themselves

Each piece: `area/what-it-is-vN.ext`, lower case, hyphens, and the artist's credit in ARTISTS.md.
